# `@prettyfull/eslint-config`

Configurations ESLint partagées du monorepo.

| Export | Usage |
| --- | --- |
| `@prettyfull/eslint-config/base` | Base commune (JS, TS, prettier, turbo) |
| `@prettyfull/eslint-config/next-js` | Apps Next.js (`web`, `admin`) |
| `@prettyfull/eslint-config/node` | Services Node.js (`backend` Hono) |
| `@prettyfull/eslint-config/react-internal` | Packages React internes (`ui`) |
